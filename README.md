# Mouvement

화면 전체를 마우스로 지휘하는 인터랙티브 음악 공간입니다. 별도 설치나 빌드 없이 실행되는 HTML, CSS, JavaScript 사이트입니다.

## 실행

프로젝트 폴더에서 `python -m http.server 4173 --directory dist`를 실행하고 `http://localhost:4173`을 여세요. `dist/index.html`을 브라우저에서 직접 열어도 연주할 수 있습니다.

## 사용

- ‘나의 연주 시작하기’를 한 번 누른 뒤 화면 위로 마우스를 움직입니다. 브라우저의 자동 재생 제한 때문에 첫 동작이 필요합니다.
- 음정은 오른쪽과 위쪽으로 갈수록 높아집니다. 기본 5음계는 자유롭게 움직여도 어울리도록 구성했습니다.
- 오른쪽 SOUND STUDIO 탭에 마우스를 올리거나 상단 소리 버튼을 눌러 설정을 엽니다. 터치 환경에서는 탭을 누릅니다.
- 기존 10종에 Electric guitar, Acid bass, Neon lead, 8-bit arcade를 더한 14가지 사운드에 맞춰 테마가 바뀝니다. 소리 설정 상단에서 전자 악기 4종을 선택합니다. 일렉기타는 오버샘플링 디스토션, 베이스는 두 옥타브 낮은 음역과 공명 필터, 리드는 디튠, 아케이드는 짧은 사각파로 합성합니다. 소리는 Web Audio로 합성하며 실제 악기 녹음 파일을 사용하지 않습니다.
- 기본 격자는 데스크톱 20×12칸입니다. 연주 설정에서 여유롭게 / 촘촘하게 / 아주 촘촘하게를 선택할 수 있으며 음역은 유지됩니다.
- ‘BGM과 합주’를 누르면 독립적인 반주가 시작됩니다. 느린 오후(로파이), 숲의 호흡(앰비언트), 별빛 산책(칠 신스) 중에서 고르고 빠르기와 반주 음량을 조절합니다. 반주는 코드·베이스·아르페지오와 스타일에 따른 퍼커션으로 구성됩니다.
- 반주는 선택한 조성과 음계에 맞춰 연주하며 8마디마다 6가지 코드 진행과 테마별 4가지 리듬 패턴을 바꿉니다. 이웃한 구간은 같은 진행·리듬을 쓰지 않으며 멜로디 음형, 코드 보이싱, 강세, 4마디 끝의 짧은 필인도 달라집니다. 시작하거나 테마를 고를 때마다 새 시드를 만들고, 재생 중에는 반주와 합주가 같은 편곡 정보를 참조합니다. 숲 테마는 드럼 없는 여백을 유지합니다. 기본적으로 사용자가 연주하는 음을 현재 코드와 음계에 모두 어울리는 가까운 음으로 조정하며, BGM 설정에서 이 기능을 끌 수 있습니다.
- ‘글로 연주’를 누르면 한글과 영문 문장을 입력하며 연주할 수 있습니다. 물리 키보드는 한글 조합 중에도 키마다 반응하며, 가상 키보드는 입력 이벤트로 연주합니다. 고정 음정과 랜덤 음정을 선택할 수 있습니다.
- 입력한 글은 저장하거나 전송하지 않습니다. 설정만 현재 브라우저에 저장됩니다. 키보드 연주는 이 사이트에 포커스가 있을 때 작동합니다.
- 문자·숫자·문장부호: 음정 연주 / 글쓰기 밖의 Space: 일시정지·재개 / Escape: 설정·글쓰기 닫기. 글쓰기 중 M과 Space는 평소대로 입력됩니다.
- 모바일에서는 화면을 손가락으로 쓸거나 글쓰기 입력창으로 연주합니다. BGM은 마우스나 키보드 연주 중에도 계속됩니다. 탭을 벗어나면 오디오가 멈추고 돌아오면 반주가 재시작됩니다.

## 검증

연주 설정의 ‘선율의 색깔’에서는 포근한 위로, 햇살 같은 기분, 비 오는 밤, 숲속의 쉼, 꿈속을 걷듯, 새로운 시작 중 고를 수 있습니다. 각 분위기는 악기·조성·음계·잔향의 조합이며 ‘직접 조성·음계 고르기’를 펼쳐 세부 조절도 가능합니다. 값을 바꾸면 ‘직접 조합한 선율’로 표시됩니다.

‘리듬·BGM’에서 BPM을 30–240으로 조절하거나 직접 입력합니다. ‘자유롭게’는 즉시 연주하고 ‘박자에 맞춰’는 한 박자·반 박자·¼박자 간격으로 연주합니다. 마우스와 글쓰기 모두 적용되며 BGM이 없어도 작동합니다. 각 간격 안의 마지막 입력만 다음 박자에 연주하므로 빠르게 입력해도 음이 긴 대기열에 쌓이지 않습니다. BGM과 입력음은 같은 오디오 시계를 사용하며 일시정지·모드 변경·탭 이탈 시 예약된 입력음이 취소됩니다.

`node --test tests/music.test.cjs`로 격자 음역, 코드와 음계의 일치, 키보드 매핑, 한글 조합과 가상 키보드의 중복 방지를 검사합니다.

소리와 설정을 위한 서버·외부 오디오 요청은 없습니다. 글꼴은 Google Fonts를 사용하고, 연결이 없으면 시스템 글꼴로 표시합니다.
