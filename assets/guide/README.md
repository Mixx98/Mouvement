# 안내용 화면 캡처

사이트의 기본 피아노 테마를 브라우저에서 직접 캡처한 원본입니다. PC는 1480×1252, 모바일은 390×844 화면입니다. `home`은 시작 전, `play`는 연주 시작 후, `volume`은 음량 조절창을 연 상태입니다.

원본 이미지에 표시를 그려 넣지 않습니다. `guide-shots.js`가 확대 영역과 버튼 위치를 정의하고, `guide.css`와 `app.js`가 그 위에 번호·테두리·설명을 표시합니다. 버튼 위치나 화면 레이아웃이 바뀌면 캡처와 좌표를 함께 갱신하세요. 단위 검사는 파일 존재와 영역 좌표를 검사하며 실제 정렬은 브라우저에서도 확인해야 합니다.
